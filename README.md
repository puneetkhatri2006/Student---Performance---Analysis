# Student Performance Analysis

## Project Overview
This project analyzes student marks using Python
and compares academic performance through graphs

## Technologies used
- Python
- Pandas
- Matplotlib
- Seaborn

## Features
- Calculate average marks
- Identify the top-performing student
- Rank students
- Analyze grade distribution
- Calculate pass/fail results
- Export student reports to CSV
- Validate student data

## Project Structure
- main.py: Main Python program
- student.csv: Student dataset
- student_performance_report.csv: Final analysis reports
- Graphs/: Contains generated graphs
- requirements.txt: Required Python Libraries

## How to Run 
1. Install the required libraries:
   pip install -r requirements.txt

2. Run the program:
   python main.py
